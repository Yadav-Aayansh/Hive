# Hive Web

React 19 single page app for Hive. Talks to the API over a cookie session.

## Requirements

- Node 24 or newer
- The Hive API running, see `../server/README.md`

## Setup

```bash
cd client
npm install
echo 'VITE_API_URL=http://localhost:3003/api/v1' > .env
npm run dev                   # http://localhost:5173
```

`VITE_API_URL` is required and prefixes every request. The API must allow this origin, so
keep `CORS_ORIGIN=http://localhost:5173` in `server/.env`.

`vite.config.ts` also proxies `/api` to `http://localhost:3003`. Set `VITE_API_URL=/api/v1`
to use it and skip CORS in development.

## Stack

React 19, Vite 8, TanStack Router, TanStack Query, react-hook-form with Zod, Tailwind v4,
shadcn on Base UI, lucide, date-fns, Manrope. Server state lives in TanStack Query, UI state
in the URL.

## Layout

```
src/
  main.tsx      router + QueryClientProvider, wires the redirect and toast handlers
  index.css     Tailwind v4 theme
  routes/       file-based routes, routeTree.gen.ts is generated
  components/
    ui/               shadcn components
    dashboard-kit.tsx PageShell, PageHeader, StatCard, FilterBar, Pagination, EmptyState
    entity-kit.tsx    HexPattern, AccentBand, IconChip, MetaChip, Meter, DateChit
  lib/
    api.ts        fetch wrapper, unwraps the envelope, throws ApiError
    queryClient.ts global query and mutation error handling
    queries/      one file per API module: query options, keys, mutations, DTOs
    constants.ts  the enum arrays, mirrored from the server
    permissions.ts can* predicates over (user, entity)
    form.ts       server field errors into react-hook-form
    optimistic.ts optimistic register, join and mark read, with rollback
  hooks/          use-mobile, use-unsaved-guard
```

`src/routeTree.gen.ts` is generated by `@tanstack/router-plugin`. Do not edit it.

## Routes

`_auth.tsx` is a pathless layout. Its `beforeLoad` fetches `/users/me`, redirects to `/login`
on 401 and to `/onboarding` if the user has no college, then renders the sidebar shell.

| Path | Access | Page |
|---|---|---|
| `/` | public | landing |
| `/login` | public | sign in |
| `/signup` | public | two step, role then details |
| `/onboarding` | campus admin without a college | create the college |
| `/verify/$serial` | public | certificate verification |
| `/dashboard` | any | role aware |
| `/clubs` | any | directory |
| `/clubs/new` | any | create a club |
| `/clubs/$slug` | any | detail, join or leave |
| `/clubs/$slug/edit` | club leader | edit, transfer leadership |
| `/clubs/$slug/members` | club audience | roster, approve, reject, kick |
| `/events` | any | directory grouped by date |
| `/events/new` | any | create under a club you lead |
| `/events/$slug` | any | detail, register or cancel |
| `/events/$slug/edit` | club leader | edit |
| `/events/$slug/manage` | leader or organizer | roster, check-in, results |
| `/announcements` | any | feed |
| `/announcements/$id` | club audience | detail, edit, delete |
| `/certificates` | student | wallet |
| `/notifications` | any | feed |
| `/profile` | any | profile and avatar |
| `/college` | campus admin | college settings |
| `/users/$id` | any | public profile |

`/college` and the edit and manage routes throw `notFound()` when the viewer lacks the role.
These guards are for the UI. The API enforces every rule again.

## Data layer

`lib/api.ts` is the only place that calls `fetch`. It sends `credentials: "include"`, unwraps
`{success, data}`, and throws an `ApiError` carrying `status`, `code`, `message`, `path` and
`details`.

`lib/queryClient.ts` handles errors for queries and mutations alike: `UNAUTHENTICATED` clears
the cache and goes to `/login`, `ONBOARDING_REQUIRED` goes to `/onboarding`,
`SERVICE_UNAVAILABLE` shows a toast. 30 second stale time, no retry on 4xx.

List pages declare `validateSearch` with a Zod schema, so filters, sort and page live in the
URL and the parsed search object is also the query key.

## Forms

react-hook-form with `zodResolver`. Server field errors arrive as `details` and go straight
in:

```ts
onError: (error) => {
  if (applyFieldErrors(error, form.setError)) return;
  toast.add({ title: isApiError(error) ? error.message : "Could not save", type: "error" });
}
```

Edit forms send only dirty fields and clear a field with `null`. `useUnsavedGuard(dirty)`
blocks navigation while a form has unsaved changes.

## Uploads

`uploadFile(file, purpose)` posts to `/uploads` and returns an `uploadId`, shown locally with
`URL.createObjectURL`. The create or update call then sends it as `logoUploadId`,
`avatarUploadId` or `bannerUploadId`.

## Styling

Tailwind v4 through `@tailwindcss/vite`, no config file. The theme is oklch custom properties
in `src/index.css`. Dark only, set on `<html>` in `index.html`.

shadcn is configured with the `base-maia` style, which generates components on Base UI. That
is why triggers take `render={<Link to="..." />}` rather than `asChild`.

## Permissions

`lib/permissions.ts` holds pure predicates such as `canEditClub`, `canRegister` and
`canRunEvent`. They read the `viewer` block the API returns on each club and event, so the
client never guesses at a rule.

`lib/constants.ts` mirrors the server enums by hand. Update it when a server enum changes.
